# Sketch
Sketch is a collection of various tools

## eu.zirk.sketch.visualnovel

`https://github.com/Xwilarg/Sketch.git?path=/Packages/eu.zirk.sketch.visualnovel`

Visual novel engine working with Ink

Show dialogs workflows within your game and let the text scale properly with its container

## eu.zirk.sketch.grid

`https://github.com/Xwilarg/Sketch.git?path=/Packages/eu.zirk.sketch.grid`

An adaptive grid

The grid itself is splitted within subgrids so you can easily extend it to huge systems with no performance loss
